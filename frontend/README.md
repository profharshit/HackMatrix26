# ThreatWho AI — Web Threat Detection & Digital Trust Intelligence

Minimalistic, high-performance web platform for AI-Powered Web Threat Detection & Digital Trust Intelligence.

Built specifically to solve the HackMatrix '26 challenge requirements:
- **Base Colors**: Pure White, Minimalist Greys, and Deep Navy Blue.
- **Strictly No Gradients**: Solid, clean, high-contrast flat surfaces, borders, and status indicators.
- **Drawer Architecture**: Collapsible and responsive side navigation drawer plus a slide-out Diagnostic Forensic Inspector drawer.
- **Guest Access**: Users do **not** have to log in to scan URLs, inspect certificates, or browse threat intelligence. A clean login interface is available for optional authenticated access.
- **eMudhra TLS Incident Analysis**: Dedicated validation module for cryptographic key generation weaknesses, Certificate Transparency, and Root CA trust chains.

---

## Quick Start

```powershell
cd frontend
npm run dev
```

Open your browser at: **`http://localhost:5173`**
